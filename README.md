# Official Sunday Footy League

The site for the Sunday Footy League (SFL) fantasy football league. It's a single `index.html` file that pulls all of its data live from the public [Sleeper API](https://docs.sleeper.com/), so there's no build step and nothing to update by hand.

Pages: Home, Matchups, Standings, Teams, Hall of Records, Victory Road, Transactions, Analytics (under development) and League Info.

Not affiliated with Sleeper.
